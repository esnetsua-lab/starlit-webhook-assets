# StarLit webhook icons

Image assets for StarLit's Discord webhook cards, served through jsDelivr:

`https://cdn.jsdelivr.net/gh/esnetsua-lab/starlit-webhook-assets@v1.0.0/icons/<name>.png`

- `icons/*.png` (256 px): message type tiles: complete, death, stopped, purchase, mythical.
- `icons/128/*.png` (128 px): the same type icons plus stat icons (points, time, floor, lives, killer, shop, items, next), sized for Discord emoji.
- `icons/watermark.png` (256 px, also 128 px): the StarLit SL mark on a transparent square, used as the card watermark, footer icon and webhook avatar (since v1.1.0).
- `icons/items/*.png` (256 px): one picture per Impel Down shop item (GPO Robux-shop art where it exists, otherwise the GPO wiki image), used on purchase webhooks.
